# Express Example 02 — CRUD Operations

## Purpose

Demonstrates CRUD operations using an in-memory data store.  

## Concepts Covered

- REST endpoints  
- Request validation  
- Route parameters  
- HTTP status codes  

## Endpoints

POST /api/v1/students  

GET /api/v1/students  

GET /api/v1/students/:id  

DELETE /api/v1/students/:id  

## Installation

```bash
npm install
```

## Run

```bas
npm start
```
