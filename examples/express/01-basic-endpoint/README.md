### Express Example 01 — Basic Endpoint

## Purpose

Demonstrates the smallest possible Express API.  

## Concepts Covered

- Route definition  
- JSON response  
- Health check endpoint  

## Endpoint

GET /api/v1/health  

## Installation

```bash
npm install
```

## Run

```bash
npm start
```

## Test

```bash
curl http://localhost:3000/api/v1/health
```
