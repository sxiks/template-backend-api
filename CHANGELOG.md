## [1.0.0] - 2026-06

### Added

* Repository restructured as a Knowledge repository.
* Added learning-oriented repository organization.
* Added `theory/` directory for backend concepts and explanations.
* Added `diagrams/` directory for architecture and flow diagrams.
* Added `exercises/` directory organized by difficulty level.
* Added `examples/` directory with FastAPI and Express examples.
* Added learning roadmap and study recommendations.
* Added framework comparison materials.

* Renamed repository from `template-backend-api` to `backend-fundamentals`.
* Replaced template-oriented documentation with educational content.
* Updated README to align with the Knowledge layer philosophy.

### Removed

* Removed template-specific project structure.
* Removed configuration templates.
* Removed testing template structure.
* Removed architecture-template responsibilities.
