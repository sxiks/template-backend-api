## Versioning Strategy

This project follows Semantic Versioning:

### MAJOR

Breaking architectural changes.

Example:

```text
1.0.0 → 2.0.0
```

### MINOR

New features, examples, or documentation.

Example:

```text
1.1.0 → 1.2.0
```

### PATCH

Corrections and minor improvements.

Example:

```text
1.0.1 → 1.0.2
```
