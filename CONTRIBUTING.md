# Contributing

Thank you for contributing to Backend Fundamentals.

This repository belongs to the Knowledge layer of the ecosystem and is intended to support learning, documentation, and practice.

---

# Contribution Principles

Contributions should focus on:

* Improving explanations and learning material
* Correcting technical inaccuracies
* Adding educational diagrams
* Adding practical exercises
* Adding framework examples
* Improving documentation quality

Contributions should not focus on:

* Production-ready applications
* Full backend projects
* Framework-specific boilerplate generation
* Infrastructure automation

Those belong to other repositories in the ecosystem.

---

# Repository Structure

```text
theory/
diagrams/
exercises/
examples/
```

Please place contributions in the appropriate directory.

---

# Writing Guidelines

* Use clear and concise English.
* Prioritize understanding over complexity.
* Prefer examples over lengthy explanations.
* Keep concepts framework-agnostic whenever possible.
* Use Markdown formatting consistently.

---

# Commit Convention

Examples:

feat: add jwt authentication guide

docs: improve http fundamentals explanation

fix: correct rest architecture diagram

refactor: reorganize authentication examples

---

# Pull Request Checklist

Before submitting:

* Content is technically accurate.
* Markdown formatting is correct.
* Links are valid.
* Examples have been tested.
* Documentation follows repository conventions.
* Changes align with the Knowledge layer philosophy.
